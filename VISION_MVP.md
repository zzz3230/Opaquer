# Opaquer — вижн MVP

## Суть продукта

Opaquer — Android-приложение-сейф, которое шифрует файлы и папки как куча одинаковых блобов по 4 MiB со случайными именами. Тот, кто получит доступ к этой папке (бэкап, другое приложение, изъятый телефон), не узнает ни содержимого, ни имён, ни размеров, ни числа файлов, ни структуры папок.

## Принципы и модель угроз

Папка с блобами на устройстве считается враждебной: её могут скопировать, подменить или вернуть к старой копии. Доверяем только приложению во время работы и двум секретам: паролю и cold key (32 случайных байта). По отдельности ни один из них архив не открывает.

| Что | Видно по папке архива? | Чем обеспечено |
| --- | --- | --- |
| Содержимое, имена, пути, типы файлов | Нет | ChaCha20-Poly1305, ключ на каждый блоб |
| Размер и число файлов | Нет | Все блобы одного размера, файлы упакованы в паки |
| Какой блоб — индекс, а какой — данные | Нет | Тип внутри шифра, адрес индекса выведен из ключа |
| Подмена или порча блоба | Обнаруживается | AEAD с id блоба в associated data |
| Откат к старой версии | Обнаруживается | Устройство помнит номер и хеш последней версии |
| Число блобов, время и частота записей | Да | Не скрывается в MVP |
| Удаление всего архива | Да, и это не предотвратить | Доступность — забота пользователя и его бэкапов |

## Что входит в MVP

1. **Создать архив.** Задать пароль; приложение создаст архив в своей папке на устройстве, сгенерирует cold key и покажет его для сохранения (QR и текст).
2. **Добавить файлы.** Из галереи или через «Поделиться», файлы до \~4 MiB; для картинок автоматически делается превью.
3. **Просматривать.** Список папок и файлов с превью, открыть файл внутри приложения или экспортировать наружу.
4. **Навести порядок.** Папки, переименование, перемещение, удаление, заметка к файлу.
5. **Сохранить.** Правки накапливаются и записываются одной версией по кнопке «Сохранить» или при выходе; если приложение упало посреди записи, данные не теряются.
6. **Заблокировать.** Корневой ключ хранится в Android Keystore, пароль вводится один раз на устройство; автоблокировка и разблокировка по биометрии.
7. **Сменить пароль.** Переписывается только индекс, файлы заново не шифруются.

## Что не входит в MVP

- Файлы больше одного блока (\~4 MiB): видео и большие PDF ждут разбиения на куски.
- Сервер, облако и синхронизация между устройствами: архив живёт на одном телефоне.
- Автоимпорт новых фото из галереи.
- Несколько архивов на одном устройстве.
- Доступ для других людей и шаринг отдельных файлов.
- Восстановление доступа без пароля или cold key.
- Уплотнение паков: место удалённых файлов освобождается, только когда пустеет весь пак.
- Скрытие времени и частоты записей (фиктивные блобы, задержки).
- iOS, десктоп и веб-клиенты.
